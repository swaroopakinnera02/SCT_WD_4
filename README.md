# To-Do Web Application

## Description

The To-Do Web Application is a task management tool developed using HTML, CSS, and JavaScript. It helps users organize daily activities by allowing them to add, edit, delete, and manage tasks efficiently. Users can mark tasks as completed and set due dates and times to improve productivity and time management.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Set date and time for tasks
* Organize tasks efficiently
* Responsive and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How to Run

1. Download or clone the project repository.
2. Open the `index.html` file in a web browser.
3. Add, manage, and track your tasks easily.

## Learning Outcomes

* DOM Manipulation
* Event Handling
* CRUD Operations
* Date and Time Management
* Local Storage Concepts
* Responsive Web Design
